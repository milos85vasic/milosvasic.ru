// visión general

Una flota, una disciplina

Una flota: grandes aplicaciones de productos sobre decenas de módulos pequeños, desacoplados, probados de forma independiente — gobernados por una Constitución de ingeniería compartida y verificados por QA anti-engaño. El lenguaje dominante es Go, con Kotlin/KMP, TypeScript/React, Python, Swift y Shell donde mejor se adapten. La tesis unificadora: una característica está terminada solo cuando un usuario real puede usarla y hay evidencia capturada para probarlo.
