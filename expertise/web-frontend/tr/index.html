Özet

TypeScript, React ve Angular — tasarım sistemleri, erişilebilirlik ve performans bütçeleri. Tasarımı gereği hızlı, erişilebilir ve çevrilmiş frontend'ler: Go/Gin çekirdeği üzerindeki Catalogizer'ın React kabuğu, Courses-Creator'ın oynatıcıları ve aynı yığındaki HelixTrack arayüzü; hepsi sitenin kendi sayfa oluşturma pipeline'ı tarafından 15 dile çevrilir.

Konu

TypeScript, React and Angular — design systems, accessibility, and performance budgets.

frontends that are fast, accessible and translated by construction

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

Catalogizer

Multi-protocol, encrypted, self-hostable media collection management (Go/Gin + React), resilient to flaky network storage and built on 21 reusable submodules. Stack: Go, Gin, React, 21 modules.

Courses-Creator

A markdown-to-video AI course pipeline with TTS and desktop, mobile and web players. Stack: TypeScript, TTS, Markdown.

HelixQA

Anti-bluff QA orchestration in Go built on one rule: the bar is not "tests pass" but "users can use the feature". It runs written YAML test banks and fully-autonomous LLM-and-vision sessions that open the real app, verify every documented feature, hunt for undocumented bugs across Android, Android TV, Web and Desktop, and refuse to score a PASS without captured runtime evidence plus AI-fix-ready tickets. Stack: Go, LLM, Computer Vision, Android, ADB.

Across these projects my focus is Frontend & desktop, QA & quality engineering — and the same discipline carries into everything I ship.
