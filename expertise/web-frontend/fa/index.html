09 — وب و فرانت‌اند

وب و فرانت‌اند

TypeScript، React و Angular — سیستم‌های طراحی، دسترس‌پذیری و بودجهٔ کارایی.

frontends that are fast, accessible and translated by construction

خلاصهٔ حرفه‌ای

TypeScript، React و Angular — سیستم‌های طراحی، دسترس‌پذیری و بودجهٔ کارایی. فرانت‌اندهایی که سریع و دسترس‌پذیرند و ترجمه در ساختارشان تعبیه شده است: پوستهٔ React در Catalogizer روی هستهٔ Go/Gin، پخش‌کننده‌های Courses-Creator و رابط کاربری HelixTrack روی همین پشته — ترجمه‌شده به ۱۵ زبان توسط خط لولهٔ تولید خودِ سایت.

Catalogizer

پوستهٔ React یک ابزار مدیریت مجموعهٔ رسانه‌ای چندپروتکلی، رمزنگاری‌شده و خودمیزبان.

Courses-Creator

خط لولهٔ دورهٔ هوش مصنوعی از markdown به ویدیو، با سه سطح پخش (دسکتاپ، موبایل، وب).

سوابق کاری

  1. Harness

    توسعه‌دهندهٔ SDK — مارس 2020 – دسامبر 2024

    بلگراد، صربستان

    توسعه‌دهندهٔ ارشد خانوادهٔ SDKهای بخش Feature Flag شرکت، با تمرکز بر همهٔ پلتفرم‌های اصلی موبایل و فراتر از آن. مشتریان و شرکا شامل AWS، Google و چند بانک بودند.

    • هدایت خانوادهٔ SDKهای چندپلتفرمی برای بخش Feature Flag — Android، iOS، Flutter، React Native و محیط‌های اجرایی سمت سرور
    • تحویل SDKهایی که شرکای AWS، Google و بانکی از آن‌ها استفاده می‌کردند، با موتور ارزیابی مشترک و APIهای متناسب با هر پلتفرم
    • مسئولیت مهندسی انتشار در هفت زبان و چهار اکوسیستم بسته‌بندی

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

  2. TN-TECH

    مهندس نرم‌افزار (قراردادی) — مارس 2017 – تاکنون

    نووی ساد، صربستان

    کار برای Globex Data (کانادا و سوئیس) روی Sekur — SekurMessenger، SekurMail، SekurSuite — و پلتفرم BusRide.

    • تحویل کلاینت‌های پیام‌رسانی امن، ایمیل و مجموعهٔ نرم‌افزاری برای Globex Data در Android و دسکتاپ
    • ساخت کلاینت موبایل پلتفرم BusRide

    Android, Java, Kotlin, C++, Qt

  3. Leica Geosystems

    مهندس نرم‌افزار — فوریه 2016 – فوریه 2020

    هیربروگ، سوئیس

    مهندسی iOS و Android برای اسکنرهای سه‌بعدی Leica Geosystems — ارتباط بی‌درنگ با سخت‌افزار، پردازش داده و همگام‌سازی. شریک: Autodesk.

    • ساخت ارتباط بی‌درنگ با سخت‌افزار اسکن سه‌بعدی از طریق Bluetooth و Wi-Fi
    • طراحی خط لوله‌های پردازش روی دستگاه و همگام‌سازی برای دادهٔ حجیم ابر نقاط
    • تحویل یکپارچه‌سازی با شریک Autodesk در کلاینت‌های Android و iOS

    Android, iOS, Java, Kotlin, Swift, C++

پروژه‌های منتخب

  • HelixTrack flagship Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular, Tauri, Kotlin, Swift

    جایگزین آزاد JIRA + Confluence: میکروسرویس‌های Go پشت یک API یکپارچهٔ مبتنی بر مسیریابی اکشن روی HTTP/3، با رمزنگاری SQLCipher برای داده‌های ذخیره‌شده و کلاینت‌های بومی وب، دسکتاپ، Android و iOS.

  • Catalogizer product Go, Gin, React, 21 modules

    مدیریت مجموعهٔ رسانه‌ای چندپروتکلی، رمزنگاری‌شده و خودمیزبان (Go/Gin + React)، مقاوم در برابر ناپایداری ذخیره‌سازی شبکه‌ای و ساخته‌شده بر پایهٔ ۲۱ زیرماژول بازاستفاده‌پذیر.

  • Courses-Creator product TypeScript, TTS, Markdown

    خط لولهٔ تولید دوره‌های هوش مصنوعی از markdown تا ویدیو با TTS، همراه با پخش‌کننده‌های دسکتاپ، موبایل و وب.

  • HelixQA pillar Go, LLM, Computer Vision, Android, ADB

    ارکستراسیون QA ضدبلوف به زبان Go بر پایهٔ یک قاعده: معیار «تست‌ها پاس شدند» نیست، بلکه «کاربران می‌توانند از قابلیت استفاده کنند» است.

  • HelixConstitution pillar Git, Shell, CI, Governance

    یک آیین‌نامهٔ مهندسی همگانی که به‌صورت زیرماژول Git توزیع می‌شود و در بیش از ۱۴۰ مخزن به ارث می‌رسد.

درخواست

TypeScript, React and Angular — design systems, accessibility, and performance budgets.

frontends that are fast, accessible and translated by construction

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

Catalogizer

Multi-protocol, encrypted, self-hostable media collection management (Go/Gin + React), resilient to flaky network storage and built on 21 reusable submodules. Stack: Go, Gin, React, 21 modules.

Courses-Creator

A markdown-to-video AI course pipeline with TTS and desktop, mobile and web players. Stack: TypeScript, TTS, Markdown.

HelixQA

Anti-bluff QA orchestration in Go built on one rule: the bar is not "tests pass" but "users can use the feature". It runs written YAML test banks and fully-autonomous LLM-and-vision sessions that open the real app, verify every documented feature, hunt for undocumented bugs across Android, Android TV, Web and Desktop, and refuse to score a PASS without captured runtime evidence plus AI-fix-ready tickets. Stack: Go, LLM, Computer Vision, Android, ADB.

Across these projects my focus is Frontend & desktop, QA & quality engineering — and the same discipline carries into everything I ship.
