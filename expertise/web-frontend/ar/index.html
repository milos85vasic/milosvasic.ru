الويب والواجهات الأمامية

TypeScript وReact وAngular — أنظمة التصميم، وإمكانية الوصول، وميزانيات الأداء.

frontends that are fast, accessible and translated by construction

نبذة مهنية

TypeScript وReact وAngular — أنظمة التصميم، وإمكانية الوصول، وميزانيات الأداء. واجهات أمامية سريعة ومتاحة للجميع ومصمَّمة للترجمة منذ البداية: واجهة React في Catalogizer فوق نواة Go/Gin، ومشغّلات Courses-Creator، وواجهة HelixTrack على الحزمة التقنية نفسها — وكلها مترجمة إلى 15 لغة بواسطة خط توليد هذا الموقع.

Catalogizer

واجهة React لمدير مجموعات وسائط متعدد البروتوكولات ومشفّر وقابل للاستضافة الذاتية.

Courses-Creator

خط إنتاج دورات بالذكاء الاصطناعي من Markdown إلى فيديو، بثلاث واجهات تشغيل (سطح المكتب والجوال والويب).

الخبرة العملية

  1. Harness

    مطوّر SDK — مارس 2020 – ديسمبر 2024

    بلغراد، صربيا

    مطوّر رئيسي لعائلة حزم SDK الخاصة بقسم Feature Flag في الشركة، مع التركيز على جميع منصات الجوال الرئيسية وما وراءها. ضمّ عملاء الشركة وشركاؤها AWS وGoogle وعدداً من البنوك.

    • قاد عائلة حزم SDK متعددة المنصات لقسم Feature Flag — Android وiOS وFlutter وReact Native وبيئات التشغيل على جانب الخادم.
    • أصدر حزم SDK استخدمتها AWS وGoogle وشركاء من القطاع المصرفي، بمحرك تقييم مشترك وواجهات برمجية مصممة وفق أعراف كل منصة.
    • تولى هندسة الإصدارات عبر سبع لغات وأربعة أنظمة لإدارة الحزم.

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

  2. TN-TECH

    مهندس برمجيات (متعاقد) — مارس 2017 – حالياً

    نوفي ساد، صربيا

    عمل لصالح Globex Data (كندا وسويسرا) على Sekur — SekurMessenger وSekurMail وSekurSuite — ومنصة BusRide.

    • سلّم تطبيقات المراسلة الآمنة والبريد وحزمة التطبيقات لشركة Globex Data على Android وسطح المكتب.
    • بنى تطبيق الجوال لمنصة BusRide.

    Android, Java, Kotlin, C++, Qt

  3. Leica Geosystems

    مهندس برمجيات — فبراير 2016 – فبراير 2020

    هيربروغ، سويسرا

    هندسة تطبيقات iOS وAndroid لماسحات Leica Geosystems ثلاثية الأبعاد — تواصل في الوقت الفعلي مع العتاد، ومعالجة البيانات ومزامنتها. الشريك: Autodesk.

    • بنى آلية تواصل في الوقت الفعلي مع عتاد المسح ثلاثي الأبعاد عبر Bluetooth وWi-Fi.
    • صمّم خطوط معالجة البيانات على الجهاز ومزامنتها للحمولات الكبيرة من سحب النقاط (point clouds).
    • أنجز التكامل مع الشريك Autodesk في تطبيقات Android وiOS.

    Android, iOS, Java, Kotlin, Swift, C++

مشاريع مختارة

  • HelixTrack flagship Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular, Tauri, Kotlin, Swift

    بديل حر لـ JIRA وConfluence: خدمات Go مصغّرة خلف واجهة برمجية موحدة تعتمد التوجيه بالإجراءات عبر HTTP/3، وتشفير SQLCipher للبيانات المخزّنة، وتطبيقات عميلة أصلية (native clients) للويب وسطح المكتب وAndroid وiOS.

  • Catalogizer product Go, Gin, React, 21 modules

    إدارة مجموعات الوسائط متعددة البروتوكولات، مشفّرة وقابلة للاستضافة الذاتية (Go/Gin وReact)، تتحمل تقلبات التخزين الشبكي غير المستقر، ومبنية على 21 وحدة فرعية قابلة لإعادة الاستخدام.

  • Courses-Creator product TypeScript, TTS, Markdown

    خط إنتاج دورات بالذكاء الاصطناعي يحوّل markdown إلى فيديو مع تحويل النص إلى كلام (TTS)، ومشغّلات لسطح المكتب والجوال والويب.

  • HelixQA pillar Go, LLM, Computer Vision, Android, ADB

    تنسيق لضمان الجودة بمنهج «مكافحة التضليل» (anti-bluff) مكتوب بلغة Go ومبني على قاعدة واحدة.

  • HelixConstitution pillar Git, Shell, CI, Governance

    كتاب قواعد هندسي شامل يُوزَّع كوحدة فرعية (submodule) في Git وتَرثه أكثر من 140 مستودعاً.

الموضوع

TypeScript, React and Angular — design systems, accessibility, and performance budgets.

frontends that are fast, accessible and translated by construction

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

Catalogizer

Multi-protocol, encrypted, self-hostable media collection management (Go/Gin + React), resilient to flaky network storage and built on 21 reusable submodules. Stack: Go, Gin, React, 21 modules.

Courses-Creator

A markdown-to-video AI course pipeline with TTS and desktop, mobile and web players. Stack: TypeScript, TTS, Markdown.

HelixQA

Anti-bluff QA orchestration in Go built on one rule: the bar is not "tests pass" but "users can use the feature". It runs written YAML test banks and fully-autonomous LLM-and-vision sessions that open the real app, verify every documented feature, hunt for undocumented bugs across Android, Android TV, Web and Desktop, and refuse to score a PASS without captured runtime evidence plus AI-fix-ready tickets. Stack: Go, LLM, Computer Vision, Android, ADB.

Across these projects my focus is Frontend & desktop, QA & quality engineering — and the same discipline carries into everything I ship.
