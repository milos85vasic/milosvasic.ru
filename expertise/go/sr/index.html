Go и бекенд

Сервиси високе пропусности, дистрибуирани системи и библиотеке од којих су изграђени.

Go services built to be operated, not just compiled

Профил

Сервиси високе пропусности, дистрибуирани системи и библиотеке од којих су изграђени. Go писан да се одржава у раду, а не само да се компајлира: HelixTrack, алтернатива за JIRA + Confluence из слободног света, и HelixMemory — јединствени мотор когнитивне меморије који обједињује четири бекенда најбоља у својој класи (Mem0, Cognee, Letta, Graphiti).

HelixTrack

Алтернатива за JIRA + Confluence из слободног света: Go микросервиси иза јединственог API-ја са усмеравањем по акцији преко HTTP/3, SQLCipher у мировању.

HelixMemory

Јединствени мотор когнитивне меморије који обједињује Mem0, Cognee, Letta и Graphiti.

Пријава за посао

High-throughput services, distributed systems, and the libraries they are built from.

Go services built to be operated, not just compiled

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

HelixAgent

A production-grade ensemble LLM service that refuses to trust a single model: it fans a prompt across many providers, runs structured multi-round debate (Proposal → Critique → Review → Synthesis), and routes by live verification scores with graceful fallback — behind an OpenAI-compatible API with an HA data layer, observability and guardrails. Stack: Go, Gin, PostgreSQL, Redis, Prometheus, OpenTelemetry.

HelixLLM

One binary, six deployment modes: OpenAI- and Anthropic-compatible inference over HTTP/3 that scales from a laptop to a multi-host cluster, with local llama.cpp inference (CUDA/Metal/ROCm) and an auto-discovering, verification-scored cloud fallback chain that always degrades to a guaranteed local model. Stack: Go, HTTP/3 QUIC, gRPC, SSE, Kafka, llama.cpp.

HelixCode

A distributed AI development platform that divides work into dependency-aware tasks across an SSH-managed worker fleet, then checkpoints and rolls back so nothing is lost when a task is interrupted — with hardware-aware model selection and a full plan/build/test/refactor lifecycle behind REST, CLI, TUI and MCP. Stack: Go, Gin, PostgreSQL, Redis, SSH, MCP.

Across these projects my focus is Backend engineering, Data — and the same discipline carries into everything I ship.
