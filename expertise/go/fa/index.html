08 — Go و بک‌اند

Go و بک‌اند

سرویس‌های پرگذردهی، سیستم‌های توزیع‌شده و کتابخانه‌هایی که از آن‌ها ساخته می‌شوند.

Go services built to be operated, not just compiled

خلاصهٔ حرفه‌ای

سرویس‌های پرگذردهی، سیستم‌های توزیع‌شده و کتابخانه‌هایی که از آن‌ها ساخته می‌شوند. کد Go که برای عملیاتی شدن نوشته شده، نه فقط برای کامپایل شدن: HelixTrack، جایگزین آزاد JIRA + Confluence، و HelixMemory — موتور حافظهٔ شناختی یکپارچه که چهار بک‌اند شاخص در رده‌ی خود (Mem0، Cognee، Letta، Graphiti) را در هم می‌آمیزد.

HelixTrack

جایگزین آزاد JIRA + Confluence: میکروسرویس‌های Go پشت یک API یکپارچهٔ مبتنی بر مسیریابی اکشن روی HTTP/3، با SQLCipher در حالت سکون.

HelixMemory

موتور حافظهٔ شناختی یکپارچه که Mem0، Cognee، Letta و Graphiti را در هم می‌آمیزد.

    بلگراد، صربستان

    توسعه‌دهندهٔ ارشد خانوادهٔ SDKهای بخش Feature Flag شرکت، با تمرکز بر همهٔ پلتفرم‌های اصلی موبایل و فراتر از آن. مشتریان و شرکا شامل AWS، Google و چند بانک بودند.

    • هدایت خانوادهٔ SDKهای چندپلتفرمی برای بخش Feature Flag — Android، iOS، Flutter، React Native و محیط‌های اجرایی سمت سرور
    • تحویل SDKهایی که شرکای AWS، Google و بانکی از آن‌ها استفاده می‌کردند، با موتور ارزیابی مشترک و APIهای متناسب با هر پلتفرم
    • مسئولیت مهندسی انتشار در هفت زبان و چهار اکوسیستم بسته‌بندی

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

    • طراحی خط لوله‌های پردازش روی دستگاه و همگام‌سازی برای دادهٔ حجیم ابر نقاط

پروژه‌های منتخب

  • HelixTrack flagship Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular, Tauri, Kotlin, Swift

    جایگزین آزاد JIRA + Confluence: میکروسرویس‌های Go پشت یک API یکپارچهٔ مبتنی بر مسیریابی اکشن روی HTTP/3، با رمزنگاری SQLCipher برای داده‌های ذخیره‌شده و کلاینت‌های بومی وب، دسکتاپ، Android و iOS.

  • HelixAgent flagship Go, Gin, PostgreSQL, Redis, Prometheus, OpenTelemetry, Neo4j, ClickHouse, Kafka

    سرویس LLM گروهی (ensemble) در سطح تولید که به یک مدل تنها اعتماد نمی‌کند.

  • HelixLLM flagship Go, HTTP/3 QUIC, gRPC, SSE, Kafka, llama.cpp

    یک باینری، شش حالت استقرار: استنتاج سازگار با OpenAI و Anthropic روی HTTP/3 که از یک لپ‌تاپ تا خوشهٔ چندمیزبانی مقیاس می‌یابد، با استنتاج محلی llama.cpp (CUDA/Metal/ROCm) و زنجیرهٔ جایگزین ابری با کشف خودکار و امتیازدهی اعتبارسنجی که همیشه در نهایت به یک مدل محلی تضمین‌شده بازمی‌گردد.

  • HelixCode flagship Go, Gin, PostgreSQL, Redis, SSH, MCP, llama.cpp

    پلتفرم توسعهٔ هوش مصنوعی توزیع‌شده که کار را به وظایف آگاه از وابستگی روی ناوگانی از workerهای مدیریت‌شده با SSH تقسیم می‌کند، سپس نقطهٔ بازیابی (checkpoint) می‌گیرد و در صورت لزوم برمی‌گردد تا با وقفهٔ یک وظیفه چیزی از دست نرود — با انتخاب مدل آگاه از سخت‌افزار و چرخهٔ کامل plan/build/test/refactor پشت REST، CLI، TUI و MCP.

  • LLMProvider core Go, Circuit Breakers, Health Monitoring

    یک رابط واحد روی ۴۳ ارائه‌دهنده، با قطع‌کننده‌های مدار (circuit breaker)، پایش سلامت، تلاش مجدد با backoff تصادفی (jitter) و کشف صادقانهٔ مدل بدون هیچ جایگزین سخت‌کدشده.

  • HelixMemory flagship Go, Mem0, Cognee, Letta, Graphiti

    موتور حافظهٔ شناختی یکپارچه که چهار بک‌اند برتر — Mem0، Cognee، Letta و Graphiti.

درخواست

High-throughput services, distributed systems, and the libraries they are built from.

Go services built to be operated, not just compiled

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

HelixAgent

A production-grade ensemble LLM service that refuses to trust a single model: it fans a prompt across many providers, runs structured multi-round debate (Proposal → Critique → Review → Synthesis), and routes by live verification scores with graceful fallback — behind an OpenAI-compatible API with an HA data layer, observability and guardrails. Stack: Go, Gin, PostgreSQL, Redis, Prometheus, OpenTelemetry.

HelixLLM

One binary, six deployment modes: OpenAI- and Anthropic-compatible inference over HTTP/3 that scales from a laptop to a multi-host cluster, with local llama.cpp inference (CUDA/Metal/ROCm) and an auto-discovering, verification-scored cloud fallback chain that always degrades to a guaranteed local model. Stack: Go, HTTP/3 QUIC, gRPC, SSE, Kafka, llama.cpp.

HelixCode

A distributed AI development platform that divides work into dependency-aware tasks across an SSH-managed worker fleet, then checkpoints and rolls back so nothing is lost when a task is interrupted — with hardware-aware model selection and a full plan/build/test/refactor lifecycle behind REST, CLI, TUI and MCP. Stack: Go, Gin, PostgreSQL, Redis, SSH, MCP.

Across these projects my focus is Backend engineering, Data — and the same discipline carries into everything I ship.
