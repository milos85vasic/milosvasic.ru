Go والأنظمة الخلفية

خدمات عالية الإنتاجية، وأنظمة موزعة، والمكتبات التي تُبنى منها.

Go services built to be operated, not just compiled

نبذة مهنية

خدمات عالية الإنتاجية، وأنظمة موزعة، والمكتبات التي تُبنى منها. شيفرة Go مبنية لتُشغَّل لا لتُبنى فحسب: HelixTrack، البديل الحر لـ JIRA وConfluence، وHelixMemory — محرك ذاكرة معرفية موحد يدمج أربعة محركات خلفية هي الأفضل في فئتها (Mem0 وCognee وLetta وGraphiti).

HelixTrack

بديل حر لـ JIRA وConfluence: خدمات Go مصغّرة خلف واجهة برمجية موحدة موجَّهة بالإجراءات عبر HTTP/3، وتشفير SQLCipher للبيانات المخزّنة.

HelixMemory

محرك ذاكرة معرفية موحد يدمج Mem0 وCognee وLetta وGraphiti.

الخبرة العملية

  1. Harness

    مطوّر SDK — مارس 2020 – ديسمبر 2024

    بلغراد، صربيا

    مطوّر رئيسي لعائلة حزم SDK الخاصة بقسم Feature Flag في الشركة، مع التركيز على جميع منصات الجوال الرئيسية وما وراءها. ضمّ عملاء الشركة وشركاؤها AWS وGoogle وعدداً من البنوك.

    • قاد عائلة حزم SDK متعددة المنصات لقسم Feature Flag — Android وiOS وFlutter وReact Native وبيئات التشغيل على جانب الخادم.
    • أصدر حزم SDK استخدمتها AWS وGoogle وشركاء من القطاع المصرفي، بمحرك تقييم مشترك وواجهات برمجية مصممة وفق أعراف كل منصة.
    • تولى هندسة الإصدارات عبر سبع لغات وأربعة أنظمة لإدارة الحزم.

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

  2. Leica Geosystems

    مهندس برمجيات — فبراير 2016 – فبراير 2020

    هيربروغ، سويسرا

    هندسة تطبيقات iOS وAndroid لماسحات Leica Geosystems ثلاثية الأبعاد — تواصل في الوقت الفعلي مع العتاد، ومعالجة البيانات ومزامنتها. الشريك: Autodesk.

    • بنى آلية تواصل في الوقت الفعلي مع عتاد المسح ثلاثي الأبعاد عبر Bluetooth وWi-Fi.
    • صمّم خطوط معالجة البيانات على الجهاز ومزامنتها للحمولات الكبيرة من سحب النقاط (point clouds).
    • أنجز التكامل مع الشريك Autodesk في تطبيقات Android وiOS.

    Android, iOS, Java, Kotlin, Swift, C++

  3. Bosch

    مطوّر SDK — يناير 2010 – يناير 2016

    بلغراد، صربيا

    مطوّر SDK رئيسي لـ SDK المركبات المتصلة (Connected Vehicles) — تواصل Bluetooth في الوقت الفعلي مع ناقل OBD2، ومعالجة البيانات وحفظها بأداء عالٍ.

    • قاد تطوير SDK المركبات المتصلة (Connected Vehicles) الذي يتواصل مع ناقل OBD2 عبر Bluetooth في الوقت الفعلي.
    • صمّم آليات عالية الأداء لتحليل بيانات القياس عن بُعد المتواصلة للمركبات وتخزينها مؤقتاً وحفظها.
    • أصدر SDK اعتمدته تكاملات شركاء قطاع السيارات.

    Android, Java, Kotlin

مشاريع مختارة

  • HelixTrack flagship Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular, Tauri, Kotlin, Swift

    بديل حر لـ JIRA وConfluence: خدمات Go مصغّرة خلف واجهة برمجية موحدة تعتمد التوجيه بالإجراءات عبر HTTP/3، وتشفير SQLCipher للبيانات المخزّنة، وتطبيقات عميلة أصلية (native clients) للويب وسطح المكتب وAndroid وiOS.

  • HelixAgent flagship Go, Gin, PostgreSQL, Redis, Prometheus, OpenTelemetry, Neo4j, ClickHouse, Kafka

    خدمة LLM قائمة على تجميع النماذج (ensemble) بمستوى الإنتاج ترفض الاعتماد على نموذج واحد.

  • HelixLLM flagship Go, HTTP/3 QUIC, gRPC, SSE, Kafka, llama.cpp

    ملف تنفيذي واحد وستة أنماط نشر: استدلال متوافق مع OpenAI وAnthropic عبر HTTP/3 يتوسع من حاسوب محمول إلى عنقود متعدد الخوادم، مع استدلال محلي عبر llama.cpp (CUDA/Metal/ROCm) وسلسلة بدائل سحابية تكتشف النماذج تلقائياً وتُرتَّب بدرجات التحقق، وتتراجع دائماً إلى نموذج محلي مضمون.

  • HelixCode flagship Go, Gin, PostgreSQL, Redis, SSH, MCP, llama.cpp

    منصة تطوير موزعة بالذكاء الاصطناعي تقسّم العمل إلى مهام تراعي التبعيات على أسطول من عقد التنفيذ (workers) يُدار عبر SSH، ثم تنشئ نقاط حفظ (checkpoints) وتتراجع عنها بحيث لا يضيع شيء عند انقطاع أي مهمة — مع اختيار للنماذج يراعي العتاد، ودورة حياة كاملة (plan/build/test/refactor) خلف REST وCLI وTUI وMCP.

  • LLMProvider core Go, Circuit Breakers, Health Monitoring

    واجهة واحدة فوق 43 مزوّداً، مع قواطع الدائرة (circuit breakers)، ومراقبة الصحة، وإعادة المحاولة بتأخير عشوائي (jittered backoff)، واكتشاف نزيه للنماذج دون بدائل مضمّنة في الشيفرة (no-hardcoded-fallback).

  • HelixMemory flagship Go, Mem0, Cognee, Letta, Graphiti

    محرك ذاكرة معرفية موحد يدمج أربع واجهات خلفية (backends) هي الأفضل في فئتها — Mem0 وCognee وLetta وGraphiti.

الموضوع

High-throughput services, distributed systems, and the libraries they are built from.

Go services built to be operated, not just compiled

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

HelixAgent

A production-grade ensemble LLM service that refuses to trust a single model: it fans a prompt across many providers, runs structured multi-round debate (Proposal → Critique → Review → Synthesis), and routes by live verification scores with graceful fallback — behind an OpenAI-compatible API with an HA data layer, observability and guardrails. Stack: Go, Gin, PostgreSQL, Redis, Prometheus, OpenTelemetry.

HelixLLM

One binary, six deployment modes: OpenAI- and Anthropic-compatible inference over HTTP/3 that scales from a laptop to a multi-host cluster, with local llama.cpp inference (CUDA/Metal/ROCm) and an auto-discovering, verification-scored cloud fallback chain that always degrades to a guaranteed local model. Stack: Go, HTTP/3 QUIC, gRPC, SSE, Kafka, llama.cpp.

HelixCode

A distributed AI development platform that divides work into dependency-aware tasks across an SSH-managed worker fleet, then checkpoints and rolls back so nothing is lost when a task is interrupted — with hardware-aware model selection and a full plan/build/test/refactor lifecycle behind REST, CLI, TUI and MCP. Stack: Go, Gin, PostgreSQL, Redis, SSH, MCP.

Across these projects my focus is Backend engineering, Data — and the same discipline carries into everything I ship.
