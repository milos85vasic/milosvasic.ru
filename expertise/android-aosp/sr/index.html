Профил

HelixQA

Anti-bluff QA orchestration in Go built on one rule: the bar is not "tests pass" but "users can use the feature". It runs written YAML test banks and fully-autonomous LLM-and-vision sessions that open the real app, verify every documented feature, hunt for undocumented bugs across Android, Android TV, Web and Desktop, and refuse to score a PASS without captured runtime evidence plus AI-fix-ready tickets. Stack: Go, LLM, Computer Vision, Android, ADB.

VisionEngine

Computer-vision plus multi-provider LLM-vision UI perception with navigation graphs. Stack: Computer Vision, LLM Vision, Navigation Graphs.

HelixConstitution

A universal engineering rulebook distributed as a Git submodule and inherited across 140+ repositories — engineering law shipped and version-pinned exactly like code. Propagation gates grep every consuming repo for required clauses, and each gate is paired with a mutation meta-test proving the gate itself isn't a sham. Stack: Git, Shell, CI, Governance.

Across these projects my focus is Android & Android TV, Infrastructure & DevOps — and the same discipline carries into everything I ship.
