04 — Android AOSP

Android AOSP

Платформа деңгейіндегі Android: жүйелік қызметтер, құрылғыны іске қосу және аппараттық интеграция.

AOSP work where the hardware is the requirement

Профиль

Платформа деңгейіндегі Android: жүйелік қызметтер, құрылғыны іске қосу және аппараттық интеграция. Аппараттық жасақтама басты талап болатын AOSP жұмысы — мұнда платформа аппаратураға бейімделеді, керісінше емес.

HelixQA

AOSP ауқымындағы CI және құрылғылар фермасында тексеру.

VisionEngine

Компьютерлік көру және навигация графтары бар көп провайдерлі LLM-көру негізіндегі UI қабылдау.

Жұмыс тәжірибесі

  1. Harness

    SDK әзірлеушісі — нау. 2020 – жел. 2024

    Белград, Сербия

    Компанияның Feature Flag бөліміне арналған SDK отбасының жетекші әзірлеушісі — барлық негізгі мобильді платформаларға және одан тыс бағытталған. Клиенттер мен әріптестер: AWS, Google және әртүрлі банктер.

    • Feature Flag бөлімінің көпплатформалы SDK отбасын басқардым — Android, iOS, Flutter, React Native және сервер жағындағы орталар.
    • AWS, Google және банк әріптестері пайдаланатын SDK жеткіздім: ортақ бағалау қозғалтқышы және әр платформаның ерекшеліктеріне сай келетін API-лармен.
    • Жеті тіл мен төрт пакет экожүйесі бойынша релиз инженериясына жауапты болдым.

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

  2. Leica Geosystems

    Бағдарламалық жасақтама инженері — ақп. 2016 – ақп. 2020

    Хербругг, Швейцария

    Leica Geosystems 3D сканерлеріне арналған iOS және Android инженериясы — аппаратурамен нақты уақыттағы байланыс, деректерді өңдеу және синхрондау. Әріптес: Autodesk.

    • Bluetooth және Wi-Fi арқылы 3D сканерлеу аппаратурасымен нақты уақыттағы байланыс жасадым.
    • Үлкен point-cloud көлемдері үшін құрылғыдағы деректерді өңдеу және синхрондау конвейерлерін жобаладым.
    • Android және iOS клиенттерінде Autodesk әріптестік интеграциясын жеткіздім.

    Android, iOS, Java, Kotlin, Swift, C++

  3. Bosch

    SDK әзірлеушісі — қаң. 2010 – қаң. 2016

    Белград, Сербия

    Connected Vehicles SDK жетекші әзірлеушісі — Bluetooth арқылы OBD2 шинасымен нақты уақыттағы байланыс, деректерді жоғары өнімді өңдеу және сақтау.

    • Bluetooth арқылы OBD2 шинасымен нақты уақытта деректер алмасатын Connected Vehicles SDK-ны басқардым.
    • Үздіксіз көлік телеметриясын жоғары өнімді талдау, буферлеу және сақтау тетіктерін әзірледім.
    • Автомобиль саласындағы әріптестердің интеграцияларында қабылданған SDK жеткіздім.

    Android, Java, Kotlin

Жұмысқа өтініш

Platform-level Android: system services, device bring-up, and hardware integration.

AOSP work where the hardware is the requirement

HelixQA

Anti-bluff QA orchestration in Go built on one rule: the bar is not "tests pass" but "users can use the feature". It runs written YAML test banks and fully-autonomous LLM-and-vision sessions that open the real app, verify every documented feature, hunt for undocumented bugs across Android, Android TV, Web and Desktop, and refuse to score a PASS without captured runtime evidence plus AI-fix-ready tickets. Stack: Go, LLM, Computer Vision, Android, ADB.

VisionEngine

Computer-vision plus multi-provider LLM-vision UI perception with navigation graphs. Stack: Computer Vision, LLM Vision, Navigation Graphs.

HelixConstitution

A universal engineering rulebook distributed as a Git submodule and inherited across 140+ repositories — engineering law shipped and version-pinned exactly like code. Propagation gates grep every consuming repo for required clauses, and each gate is paired with a mutation meta-test proving the gate itself isn't a sham. Stack: Git, Shell, CI, Governance.

Across these projects my focus is Android & Android TV, Infrastructure & DevOps — and the same discipline carries into everything I ship.
