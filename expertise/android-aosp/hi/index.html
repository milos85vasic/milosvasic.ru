प्रोफ़ाइल

प्लेटफ़ॉर्म-स्तर का Android: सिस्टम सर्विसेज़, डिवाइस ब्रिंग-अप और हार्डवेयर इंटीग्रेशन। ऐसा AOSP काम जहाँ हार्डवेयर ही आवश्यकता है — और प्लेटफ़ॉर्म को उसके अनुरूप ढलना पड़ता है, उल्टा नहीं।

अनुभव

  1. Harness

    SDK डेवलपर — मार्च 2020 – दिस॰ 2024

    बेलग्रेड, सर्बिया

    कंपनी के Feature Flag डिवीज़न के SDK परिवार के लीड डेवलपर — सभी प्रमुख मोबाइल प्लेटफ़ॉर्म और उनसे आगे। ग्राहकों और पार्टनरों में AWS, Google और कई बैंक शामिल थे।

    • Feature Flag डिवीज़न के लिए मल्टी-प्लेटफ़ॉर्म SDK परिवार का नेतृत्व किया — Android, iOS, Flutter, React Native और सर्वर-साइड रनटाइम
    • ऐसे SDK शिप किए जिन्हें AWS, Google और बैंकिंग पार्टनर उपयोग करते हैं — साझा इवैल्यूएशन इंजन और हर प्लेटफ़ॉर्म की अपनी शैली के अनुरूप API के साथ
    • सात भाषाओं और चार पैकेज इकोसिस्टम में रिलीज़ इंजीनियरिंग की ज़िम्मेदारी संभाली

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

  2. Leica Geosystems

    सॉफ़्टवेयर इंजीनियर — फ़र॰ 2016 – फ़र॰ 2020

    हीरब्रुग, स्विट्ज़रलैंड

    Leica Geosystems के 3D स्कैनर के लिए iOS और Android इंजीनियरिंग — हार्डवेयर के साथ रियल-टाइम संचार, डेटा प्रोसेसिंग और सिंक्रोनाइज़ेशन। पार्टनर: Autodesk।

    • Bluetooth और Wi-Fi के ज़रिए 3D स्कैनिंग हार्डवेयर के साथ रियल-टाइम डिवाइस संचार बनाया
    • बड़े पॉइंट-क्लाउड पेलोड के लिए ऑन-डिवाइस डेटा प्रोसेसिंग और सिंक्रोनाइज़ेशन पाइपलाइन डिज़ाइन कीं
    • Android और iOS क्लाइंट में Autodesk पार्टनर इंटीग्रेशन डिलीवर किया

    Android, iOS, Java, Kotlin, Swift, C++

  3. Bosch

    SDK डेवलपर — जन॰ 2010 – जन॰ 2016

    बेलग्रेड, सर्बिया

    Connected Vehicles SDK के लीड डेवलपर — Bluetooth के ज़रिए OBD2 बस से रियल-टाइम संचार, हाई-परफ़ॉर्मेंस डेटा प्रोसेसिंग और परसिस्टेंस।

    • Connected Vehicles SDK का नेतृत्व किया — Bluetooth के ज़रिए OBD2 बस से रियल-टाइम संचार
    • लगातार आने वाली वाहन टेलीमेट्री के लिए हाई-परफ़ॉर्मेंस पार्सिंग, बफ़रिंग और परसिस्टेंस इंजीनियर किए
    • ऐसा SDK शिप किया जिसे ऑटोमोटिव पार्टनर इंटीग्रेशन में व्यापक रूप से अपनाया गया

HelixQA

Anti-bluff QA orchestration in Go built on one rule: the bar is not "tests pass" but "users can use the feature". It runs written YAML test banks and fully-autonomous LLM-and-vision sessions that open the real app, verify every documented feature, hunt for undocumented bugs across Android, Android TV, Web and Desktop, and refuse to score a PASS without captured runtime evidence plus AI-fix-ready tickets. Stack: Go, LLM, Computer Vision, Android, ADB.

VisionEngine

Computer-vision plus multi-provider LLM-vision UI perception with navigation graphs. Stack: Computer Vision, LLM Vision, Navigation Graphs.

HelixConstitution

A universal engineering rulebook distributed as a Git submodule and inherited across 140+ repositories — engineering law shipped and version-pinned exactly like code. Propagation gates grep every consuming repo for required clauses, and each gate is paired with a mutation meta-test proving the gate itself isn't a sham. Stack: Git, Shell, CI, Governance.

Across these projects my focus is Android & Android TV, Infrastructure & DevOps — and the same discipline carries into everything I ship.
