Досвед працы

  1. Harness

    SDK-распрацоўшчык — сак 2020 – сне 2024

    Бялград, Сербія

    Вядучы распрацоўшчык сямейства SDK для падраздзялення Feature Flag, арыентаванага на ўсе асноўныя мабільныя платформы і не толькі. Сярод кліентаў і партнёраў — AWS, Google і розныя банкі.

    • Узначальваў сямейства SDK для падраздзялення Feature Flag — Android, iOS, Flutter, React Native і серверныя асяроддзі выканання
    • Выпусціў SDK, якімі карысталіся AWS, Google і банкаўскія партнёры, з агульным рухавіком ацэнкі флагаў і ідыяматычнымі API для кожнай платформы
    • Адказваў за рэліз-інжынерыю для сямі моў праграмавання і чатырох экасістэм пакетаў

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

  2. Leica Geosystems

    Інжынер-праграміст — лют 2016 – лют 2020

    Хербруг, Швейцарыя

    Распрацоўка iOS- і Android-праграм для 3D-сканераў Leica Geosystems — сувязь з абсталяваннем у рэжыме рэальнага часу, апрацоўка і сінхранізацыя даных. Партнёр: Autodesk.

    • Рэалізаваў сувязь у рэжыме рэальнага часу з 3D-сканерамі праз Bluetooth і Wi-Fi
    • Спраектаваў апрацоўку даных на прыладзе і канвееры сінхранізацыі для вялікіх аб’ёмаў хмар кропак
    • Выканаў інтэграцыю з партнёрам Autodesk у кліентах для Android і iOS

    Android, iOS, Java, Kotlin, Swift, C++

  3. Bosch

    SDK-распрацоўшчык — сту 2010 – сту 2016

    Бялград, Сербія

    Вядучы распрацоўшчык SDK для Connected Vehicles — сувязь з шынай OBD2 праз Bluetooth у рэжыме рэальнага часу, высокапрадукцыйная апрацоўка і захаванне даных.

    • Узначальваў распрацоўку SDK для Connected Vehicles, які ў рэжыме рэальнага часу абменьваўся данымі з шынай OBD2 праз Bluetooth
    • Распрацаваў высокапрадукцыйныя механізмы разбору, буферызацыі і захавання бесперапыннай тэлеметрыі аўтамабіляў
    • Выпусціў SDK, якім карысталіся ў інтэграцыях з аўтамабільнымі партнёрамі

    Android, Java, Kotlin

HelixQA

Anti-bluff QA orchestration in Go built on one rule: the bar is not "tests pass" but "users can use the feature". It runs written YAML test banks and fully-autonomous LLM-and-vision sessions that open the real app, verify every documented feature, hunt for undocumented bugs across Android, Android TV, Web and Desktop, and refuse to score a PASS without captured runtime evidence plus AI-fix-ready tickets. Stack: Go, LLM, Computer Vision, Android, ADB.

VisionEngine

Computer-vision plus multi-provider LLM-vision UI perception with navigation graphs. Stack: Computer Vision, LLM Vision, Navigation Graphs.

HelixConstitution

A universal engineering rulebook distributed as a Git submodule and inherited across 140+ repositories — engineering law shipped and version-pinned exactly like code. Propagation gates grep every consuming repo for required clauses, and each gate is paired with a mutation meta-test proving the gate itself isn't a sham. Stack: Git, Shell, CI, Governance.

Across these projects my focus is Android & Android TV, Infrastructure & DevOps — and the same discipline carries into everything I ship.
