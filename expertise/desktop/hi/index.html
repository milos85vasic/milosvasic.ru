प्रोफ़ाइल

Electron और Tauri, नेटिव ब्रिज और ऑफ़लाइन-फ़र्स्ट डेस्कटॉप प्रोडक्ट — जो रिलीज़ होते हैं, अपडेट होते हैं और कोड-साइन किए रहते हैं। डेस्कटॉप क्षेत्र: HelixTrack का JIRA विकल्प और Courses-Creator, दोनों उपयोगकर्ता की अपनी मशीन पर चलते हैं, ऑफ़लाइन भी।

HelixTrack

free-world JIRA + Confluence विकल्प, अपने डेस्कटॉप क्लाइंट के साथ।

Courses-Creator

AI कोर्स पाइपलाइन, अपने डेस्कटॉप प्लेयर के साथ।

अनुभव

  1. Harness

    SDK डेवलपर — मार्च 2020 – दिस॰ 2024

    बेलग्रेड, सर्बिया

    कंपनी के Feature Flag डिवीज़न के SDK परिवार के लीड डेवलपर — सभी प्रमुख मोबाइल प्लेटफ़ॉर्म और उनसे आगे। ग्राहकों और पार्टनरों में AWS, Google और कई बैंक शामिल थे।

    • Feature Flag डिवीज़न के लिए मल्टी-प्लेटफ़ॉर्म SDK परिवार का नेतृत्व किया — Android, iOS, Flutter, React Native और सर्वर-साइड रनटाइम
    • ऐसे SDK शिप किए जिन्हें AWS, Google और बैंकिंग पार्टनर उपयोग करते हैं — साझा इवैल्यूएशन इंजन और हर प्लेटफ़ॉर्म की अपनी शैली के अनुरूप API के साथ
    • सात भाषाओं और चार पैकेज इकोसिस्टम में रिलीज़ इंजीनियरिंग की ज़िम्मेदारी संभाली

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

  2. TN-TECH

    सॉफ़्टवेयर इंजीनियर (कॉन्ट्रैक्ट) — मार्च 2017 – वर्तमान

    नोवी साद, सर्बिया

    Globex Data (कनाडा और स्विट्ज़रलैंड) के लिए Sekur पर काम — SekurMessenger, SekurMail, SekurSuite — और BusRide प्लेटफ़ॉर्म।

    • Globex Data के लिए Android और डेस्कटॉप पर सुरक्षित मैसेजिंग, मेल और सुइट क्लाइंट डिलीवर किए
    • BusRide प्लेटफ़ॉर्म का मोबाइल क्लाइंट बनाया

    Android, Java, Kotlin, C++, Qt

  3. Leica Geosystems

    सॉफ़्टवेयर इंजीनियर — फ़र॰ 2016 – फ़र॰ 2020

    हीरब्रुग, स्विट्ज़रलैंड

    Leica Geosystems के 3D स्कैनर के लिए iOS और Android इंजीनियरिंग — हार्डवेयर के साथ रियल-टाइम संचार, डेटा प्रोसेसिंग और सिंक्रोनाइज़ेशन। पार्टनर: Autodesk।

    • Bluetooth और Wi-Fi के ज़रिए 3D स्कैनिंग हार्डवेयर के साथ रियल-टाइम डिवाइस संचार बनाया
    • बड़े पॉइंट-क्लाउड पेलोड के लिए ऑन-डिवाइस डेटा प्रोसेसिंग और सिंक्रोनाइज़ेशन पाइपलाइन डिज़ाइन कीं
    • Android और iOS क्लाइंट में Autodesk पार्टनर इंटीग्रेशन डिलीवर किया

    Android, iOS, Java, Kotlin, Swift, C++

चुनिंदा प्रोजेक्ट

  • HelixTrack flagship Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular, Tauri, Kotlin, Swift

    फ़्री-वर्ल्ड JIRA + Confluence विकल्प: HTTP/3 पर एकीकृत एक्शन-रूटेड API के पीछे Go माइक्रोसर्विसेज़, at-rest SQLCipher एन्क्रिप्शन, और नेटिव Web.

  • Catalogizer product Go, Gin, React, 21 modules

    मल्टी-प्रोटोकॉल, एन्क्रिप्टेड, सेल्फ़-होस्ट करने योग्य मीडिया कलेक्शन मैनेजमेंट (Go/Gin + React).

  • Courses-Creator product TypeScript, TTS, Markdown

    TTS तथा डेस्कटॉप, मोबाइल और वेब प्लेयर के साथ markdown से वीडियो बनाने वाली AI कोर्स पाइपलाइन।

  • HelixCode flagship Go, Gin, PostgreSQL, Redis, SSH, MCP, llama.cpp

    डिस्ट्रिब्यूटेड AI डेवलपमेंट प्लेटफ़ॉर्म जो काम को निर्भरता-सजग टास्क में बाँटकर SSH-प्रबंधित वर्कर फ़्लीट पर चलाता है.

  • HelixQA pillar Go, LLM, Computer Vision, Android, ADB

    Go में Anti-bluff QA ऑर्केस्ट्रेशन, जो एक नियम पर टिका है: पैमाना “टेस्ट पास हुए” नहीं.

आवेदन

Electron and Tauri, native bridges, and offline-first desktop products.

desktop products that ship, update and stay signed

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

Catalogizer

Multi-protocol, encrypted, self-hostable media collection management (Go/Gin + React), resilient to flaky network storage and built on 21 reusable submodules. Stack: Go, Gin, React, 21 modules.

Courses-Creator

A markdown-to-video AI course pipeline with TTS and desktop, mobile and web players. Stack: TypeScript, TTS, Markdown.

HelixCode

A distributed AI development platform that divides work into dependency-aware tasks across an SSH-managed worker fleet, then checkpoints and rolls back so nothing is lost when a task is interrupted — with hardware-aware model selection and a full plan/build/test/refactor lifecycle behind REST, CLI, TUI and MCP. Stack: Go, Gin, PostgreSQL, Redis, SSH, MCP.

Across these projects my focus is Frontend & desktop, Infrastructure & DevOps — and the same discipline carries into everything I ship.
