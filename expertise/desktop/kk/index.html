10 — Десктоп инженериясы

Десктоп инженериясы

Electron және Tauri, нативті көпірлер және offline-first десктоп өнімдері.

desktop products that ship, update and stay signed

Профиль

Electron және Tauri, нативті көпірлер және offline-first десктоп өнімдері — жеткізіледі, жаңартылады және қол қойылған күйінде қалады. Десктоп бағыты: HelixTrack-тің JIRA-ға балама өнімі және Courses-Creator, екеуі де пайдаланушыны оның компьютерінде, offline режимінде де қарсы алады.

HelixTrack

Десктоп бағыты бар JIRA + Confluence-ке еркін балама.

Courses-Creator

Десктоп ойнатқышы бар ЖИ курс конвейері.

Жұмыс тәжірибесі

  1. Harness

    SDK әзірлеушісі — нау. 2020 – жел. 2024

    Белград, Сербия

    Компанияның Feature Flag бөліміне арналған SDK отбасының жетекші әзірлеушісі — барлық негізгі мобильді платформаларға және одан тыс бағытталған. Клиенттер мен әріптестер: AWS, Google және әртүрлі банктер.

    • Feature Flag бөлімінің көпплатформалы SDK отбасын басқардым — Android, iOS, Flutter, React Native және сервер жағындағы орталар.
    • AWS, Google және банк әріптестері пайдаланатын SDK жеткіздім: ортақ бағалау қозғалтқышы және әр платформаның ерекшеліктеріне сай келетін API-лармен.
    • Жеті тіл мен төрт пакет экожүйесі бойынша релиз инженериясына жауапты болдым.

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

  2. TN-TECH

    Бағдарламалық жасақтама инженері (келісімшарт бойынша) — нау. 2017 – қазір

    Нови-Сад, Сербия

    Globex Data (Канада және Швейцария) үшін Sekur — SekurMessenger, SekurMail, SekurSuite — және BusRide платформасы бойынша жұмыс істедім.

    • Globex Data үшін Android және десктоп платформаларында қауіпсіз мессенджер, пошта және suite клиенттерін жеткіздім.
    • BusRide платформасының мобильді клиентін құрдым.

    Android, Java, Kotlin, C++, Qt

  3. Leica Geosystems

    Бағдарламалық жасақтама инженері — ақп. 2016 – ақп. 2020

    Хербругг, Швейцария

    Leica Geosystems 3D сканерлеріне арналған iOS және Android инженериясы — аппаратурамен нақты уақыттағы байланыс, деректерді өңдеу және синхрондау. Әріптес: Autodesk.

    • Bluetooth және Wi-Fi арқылы 3D сканерлеу аппаратурасымен нақты уақыттағы байланыс жасадым.
    • Үлкен point-cloud көлемдері үшін құрылғыдағы деректерді өңдеу және синхрондау конвейерлерін жобаладым.
    • Android және iOS клиенттерінде Autodesk әріптестік интеграциясын жеткіздім.

    Android, iOS, Java, Kotlin, Swift, C++

Таңдаулы жобалар

  • HelixTrack flagship Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular, Tauri, Kotlin, Swift

    JIRA + Confluence-ке еркін (ашық) балама: бірыңғай action-routed API арқылы HTTP/3 үстіндегі Go микросервистері.

  • Catalogizer product Go, Gin, React, 21 modules

    Көп протоколды, шифрланған, өздігінен орналастырылатын медиа жинақты басқару (Go/Gin + React).

  • Courses-Creator product TypeScript, TTS, Markdown

    TTS-і және десктоп, мобильді және Web ойнатқыштары бар markdown-нан бейнеге түрлендіретін ЖИ курс конвейері.

  • HelixCode flagship Go, Gin, PostgreSQL, Redis, SSH, MCP, llama.cpp

    Жұмысты тәуелділікті ескеретін тапсырмаларға бөліп, SSH арқылы басқарылатын жұмысшы түйіндер тобына таратып.

  • HelixQA pillar Go, LLM, Computer Vision, Android, ADB

    Go тіліндегі anti-bluff QA оркестрациясы, бір ережеге негізделген: өлшем — «тесттер өтті» емес, «пайдаланушылар функцияны қолдана алады».

Жұмысқа өтініш

Electron and Tauri, native bridges, and offline-first desktop products.

desktop products that ship, update and stay signed

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

Catalogizer

Multi-protocol, encrypted, self-hostable media collection management (Go/Gin + React), resilient to flaky network storage and built on 21 reusable submodules. Stack: Go, Gin, React, 21 modules.

Courses-Creator

A markdown-to-video AI course pipeline with TTS and desktop, mobile and web players. Stack: TypeScript, TTS, Markdown.

HelixCode

A distributed AI development platform that divides work into dependency-aware tasks across an SSH-managed worker fleet, then checkpoints and rolls back so nothing is lost when a task is interrupted — with hardware-aware model selection and a full plan/build/test/refactor lifecycle behind REST, CLI, TUI and MCP. Stack: Go, Gin, PostgreSQL, Redis, SSH, MCP.

Across these projects my focus is Frontend & desktop, Infrastructure & DevOps — and the same discipline carries into everything I ship.
