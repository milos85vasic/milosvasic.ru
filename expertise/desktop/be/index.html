Распрацоўка дэсктопных праграм

desktop products that ship, update and stay signed

Профіль

Electron і Tauri, натыўныя масты і дэсктопныя прадукты з падтрымкай працы без сеткі — якія выпускаюцца, абнаўляюцца і застаюцца падпісанымі. Дэсктопная паверхня: альтэрнатыва JIRA ад HelixTrack і Courses-Creator, абодва працуюць на машыне карыстальніка, у тым ліку без сеткі.

HelixTrack

Альтэрнатыва JIRA + Confluence для свабоднага свету з дэсктопнай паверхняй.

Courses-Creator

Канвеер ШІ-курсаў з дэсктопным прайгравальнікам.

Досвед працы

  1. Harness

    SDK-распрацоўшчык — сак 2020 – сне 2024

    Бялград, Сербія

    Вядучы распрацоўшчык сямейства SDK для падраздзялення Feature Flag, арыентаванага на ўсе асноўныя мабільныя платформы і не толькі. Сярод кліентаў і партнёраў — AWS, Google і розныя банкі.

    • Узначальваў сямейства SDK для падраздзялення Feature Flag — Android, iOS, Flutter, React Native і серверныя асяроддзі выканання
    • Выпусціў SDK, якімі карысталіся AWS, Google і банкаўскія партнёры, з агульным рухавіком ацэнкі флагаў і ідыяматычнымі API для кожнай платформы
    • Адказваў за рэліз-інжынерыю для сямі моў праграмавання і чатырох экасістэм пакетаў

    Android, iOS, Flutter, React Native, TypeScript, JavaScript, Java, Kotlin, Swift, Go, Ruby

  2. TN-TECH

    Інжынер-праграміст (кантракт) — сак 2017 – па цяперашні час

    Нові-Сад, Сербія

    Праца для Globex Data (Канада і Швейцарыя) над Sekur — SekurMessenger, SekurMail, SekurSuite — і над платформай BusRide.

    • Выпусціў кліенты для бяспечных паведамленняў, пошты і пакета праграм Globex Data на Android і дэсктопе
    • Распрацаваў мабільны кліент платформы BusRide

    Android, Java, Kotlin, C++, Qt

  3. Leica Geosystems

    Інжынер-праграміст — лют 2016 – лют 2020

    Хербруг, Швейцарыя

    Распрацоўка iOS- і Android-праграм для 3D-сканераў Leica Geosystems — сувязь з абсталяваннем у рэжыме рэальнага часу, апрацоўка і сінхранізацыя даных. Партнёр: Autodesk.

    • Рэалізаваў сувязь у рэжыме рэальнага часу з 3D-сканерамі праз Bluetooth і Wi-Fi
    • Спраектаваў апрацоўку даных на прыладзе і канвееры сінхранізацыі для вялікіх аб’ёмаў хмар кропак
    • Выканаў інтэграцыю з партнёрам Autodesk у кліентах для Android і iOS

    Android, iOS, Java, Kotlin, Swift, C++

Абраныя праекты

  • HelixTrack flagship Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular, Tauri, Kotlin, Swift

    Альтэрнатыва JIRA + Confluence для свабоднага свету: мікрасэрвісы на Go за адзіным API з маршрутызацыяй па дзеяннях праз HTTP/3.

  • Catalogizer product Go, Gin, React, 21 modules

    Шматпратакольнае, зашыфраванае кіраванне медыякалекцыяй з магчымасцю самастойнага разгортвання (Go/Gin + React).

  • Courses-Creator product TypeScript, TTS, Markdown

    Канвеер ШІ-курсаў з Markdown у відэа з TTS і прайгравальнікамі для дэсктопа, мабільных прылад і вэбу.

  • HelixCode flagship Go, Gin, PostgreSQL, Redis, SSH, MCP, llama.cpp

    Размеркаваная платформа распрацоўкі з ШІ, якая дзеліць працу на задачы з улікам залежнасцей паміж воркерамі, якімі кіруюць праз SSH.

  • HelixQA pillar Go, LLM, Computer Vision, Android, ADB

    Anti-bluff QA-аркестрацыя на Go, пабудаваная на адным правіле: мерка — не «тэсты праходзяць», а «карыстальнікі могуць карыстацца функцыяй».

Заява на вакансію

Electron and Tauri, native bridges, and offline-first desktop products.

desktop products that ship, update and stay signed

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

Catalogizer

Multi-protocol, encrypted, self-hostable media collection management (Go/Gin + React), resilient to flaky network storage and built on 21 reusable submodules. Stack: Go, Gin, React, 21 modules.

Courses-Creator

A markdown-to-video AI course pipeline with TTS and desktop, mobile and web players. Stack: TypeScript, TTS, Markdown.

HelixCode

A distributed AI development platform that divides work into dependency-aware tasks across an SSH-managed worker fleet, then checkpoints and rolls back so nothing is lost when a task is interrupted — with hardware-aware model selection and a full plan/build/test/refactor lifecycle behind REST, CLI, TUI and MCP. Stack: Go, Gin, PostgreSQL, Redis, SSH, MCP.

Across these projects my focus is Frontend & desktop, Infrastructure & DevOps — and the same discipline carries into everything I ship.
