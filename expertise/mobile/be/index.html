Мабільная распрацоўка

Натыўная і кросплатформенная распрацоўка для Android, iOS, Flutter і React Native.

one engineer owning the whole mobile surface

Профіль

Натыўная і кросплатформенная распрацоўка для Android, iOS, Flutter і React Native — як адзін інжынер, што адказвае за ўсю мабільную паверхню: межы SDK, платформенныя каналы, CI і аўтаматызацыя рэлізаў, а таксама давераная апаратная аснова, якая ўсё гэта трымае. Для ШІ гэта азначае, што сам платформенны пласт ужо з’яўляецца прадуктам аркестрацыі.

HelixTrack

Флагманскі інструмент мабільнай паверхні: альтэрнатыва JIRA/Confluence, пабудаваная ў маштабе SDK.

VisionEngine

Камп’ютарны зрок плюс успрыманне UI праз LLM-зрок ад некалькіх правайдэраў з графамі навігацыі.

Заява на вакансію

Native and cross-platform delivery across Android, iOS, Flutter and React Native.

one engineer owning the whole mobile surface

HelixTrack

A free-world JIRA + Confluence alternative: Go microservices behind a unified action-routed API over HTTP/3, SQLCipher encryption at rest, and native Web, Desktop, Android and iOS clients. Stack: Go, Gin, HTTP/3, PostgreSQL, SQLCipher, Angular.

HelixQA

Anti-bluff QA orchestration in Go built on one rule: the bar is not "tests pass" but "users can use the feature". It runs written YAML test banks and fully-autonomous LLM-and-vision sessions that open the real app, verify every documented feature, hunt for undocumented bugs across Android, Android TV, Web and Desktop, and refuse to score a PASS without captured runtime evidence plus AI-fix-ready tickets. Stack: Go, LLM, Computer Vision, Android, ADB.

Catalogizer

Multi-protocol, encrypted, self-hostable media collection management (Go/Gin + React), resilient to flaky network storage and built on 21 reusable submodules. Stack: Go, Gin, React, 21 modules.

Courses-Creator

A markdown-to-video AI course pipeline with TTS and desktop, mobile and web players. Stack: TypeScript, TTS, Markdown.

Across these projects my focus is Android & Android TV, Cross-platform & mobile SDKs — and the same discipline carries into everything I ship.
