सामग्री मार्कडाउन इनपुट, प्रोफेशनल वीडियो कोर्स आउटपुट — AI-संवर्धित, बहु-प्लेटफ़ॉर्म।

Courses-Creator एक टूलकिट है जो मार्कडाउन स्क्रिप्ट्स को AI-संचालित संवर्द्धनों के साथ प्रोफेशनल वीडियो कोर्स में बदलता है: बहु-LLM सामग्री संवर्धन (OpenAI/Anthropic/Ollama), उच्च-गुणवत्ता वाली TTS और बैकग्राउंड म्यूज़िक, तथा डेस्कटॉप, मोबाइल और वेब प्लेयर्स — सभी Docker-तैनात, Prometheus/Grafana मॉनिटरिंग के साथ।

मार्कडाउन को आकर्षक वीडियो कोर्स में बदलता है। एक Go प्रोसेसिंग इंजन सामग्री को कई LLM प्रदाताओं के माध्यम से संवर्धित करता है, कथन (Bark/SpeechT5 TTS) और संगीत उत्पन्न करता है, तथा Electron डेस्कटॉप, React Native मोबाइल और React वेब प्लेयर्स पर वितरित करता है — पूर्ण Docker तैनाती और मॉनिटरिंग के साथ।

आमतौर पर एक वीडियो कोर्स का निर्माण एक छोटे प्रोडक्शन स्टूडियो के बराबर काम होता है: स्क्रिप्टिंग, कथन रिकॉर्डिंग, संगीत का चयन, संपादन, एन्कोडिंग, और फिर हर उस प्लेटफ़ॉर्म के लिए प्लेयर्स बनाना जिसका उपयोग शिक्षार्थी कर सकते हैं। Courses-Creator इस पूरी प्रक्रिया को एक ही इनपुट — मार्कडाउन स्क्रिप्ट — और एक ही कमांड में समेट देता है। इसके केंद्र में एक Go कोर-प्रोसेसर है जो एक पूर्ण वीडियो/ऑडियो पाइपलाइन चलाता है: यह लिखित सामग्री को कई LLM प्रदाताओं (OpenAI, Anthropic, और स्थानीय Ollama) के माध्यम से संवर्धित करता है, टेक्स्ट-टू-स्पीच इंजनों (Bark, SpeechT5) से प्राकृतिक कथन संश्लेषित करता है, बैकग्राउंड म्यूज़िक जोड़ता है, और सभी टुकड़ों को तैयार कोर्स वीडियो में संयोजित करता है। लेखक का काम विचारों और शब्दों के स्तर पर ही रहता है; सिस्टम आवाज़, संगीत और प्रोडक्शन का काम संभालता है। और चूँकि एक कोर्स तभी उपयोगी होता है जब लोग उसे देख सकें, इसलिए वितरण बहु-प्लेटफ़ॉर्म के लिए डिज़ाइन किया गया है: एक Electron डेस्कटॉप क्रिएटर ऐप, एक React Native मोबाइल प्लेयर, और एक React वेब प्लेयर — सभी एक ही REST API और बैकग्राउंड जॉब सिस्टम द्वारा संचालित। एक बैकएंड, तीन प्रथम श्रेणी के क्लाइंट, हर प्लेटफ़ॉर्म के लिए अलग से कार्यान्वयन की आवश्यकता नहीं।

महत्वपूर्ण बात यह है कि यह एक प्रोडक्शन इंफ्रास्ट्रक्चर है, न कि केवल एक डेमो रील। बैकएंड में PostgreSQL दृढ़ता, बैकग्राउंड जॉब प्रोसेसिंग शामिल है ताकि लंबी TTS/वीडियो रेंडरिंग कभी API को ब्लॉक न करें, टूल-संवर्धित संवर्द्धन के लिए MCP सर्वर कार्यान्वयन, Prometheus मेट्रिक्स, JWT प्रमाणीकरण, और एक nginx रिवर्स प्रॉक्सी — और यह सब एक Docker Compose तैनाती के रूप में आता है, जिसमें Grafana/Prometheus मॉनिटरिंग प्रोफाइल शामिल हैं जिन्हें एक ही चरण में स्थापित किया जा सकता है। AI एक संवर्द्धन परत है, निर्भरता नहीं: हर LLM प्रदाता वैकल्पिक है, इसलिए पाइपलाइन बुनियादी संचालन के लिए शून्य API कुंजियों के साथ चल सकती है और जैसे ही कुंजियाँ प्रदान की जाती हैं, प्रीमियम संवर्द्धन सक्रिय हो जाता है। यही एक निर्णय इस टूल को एक लैपटॉप पर ऑफलाइन काम करने वाले शौकिया और अपने पसंदीदा प्रदाता को जोड़ने वाले उद्यम — दोनों के लिए उपयुक्त बनाता है। और इसके नीचे की पूरी मीडिया पाइपलाइन यूनिट, इंटीग्रेशन और एंड-टू-एंड टेस्ट्स द्वारा कवर की गई है, न कि केवल विश्वास पर आधारित।

मैन्युअल रूप से कोर्स वीडियो का निर्माण धीमा होता है: लिखना, कथन रिकॉर्ड करना, संगीत जोड़ना और संपादन — हर चरण में प्रयास और विशेषज्ञ टूल्स की आवश्यकता होती है। Courses-Creator इसे एक मार्कडाउन-संचालित पाइपलाइन में समेट देता है ताकि एक ही सोर्स स्क्रिप्ट एक तैयार कोर्स बन जाए, जिसमें AI उन खामियों को भरता है जिन्हें मनुष्य अन्यथा हाथ से भरते।

सामग्री

यह कोर्स निर्माण को एक विशेषज्ञ, बहु-उपकरण शिल्प से एक दोहराने योग्य सॉफ़्टवेयर पाइपलाइन में बदल देता है: लेखन, AI संवर्धन, कथन और संगीत निर्माण, तथा बहु-मंच प्लेबैक—सब कुछ एक ही तैनात करने योग्य स्टैक में समाहित है। बिना-API-कुंजी संचालन में सहज गिरावट ही इसकी शांत महाशक्ति है—एक ही कोडबेस बजट-सचेत एकल रचनाकार और प्रीमियम प्रदाता अनुबंध वाली एंटरप्राइज़ दोनों की सेवा करता है, बीच में कुछ भी दोबारा लिखने की ज़रूरत नहीं पड़ती।

  • मार्कडाउन-से-वीडियो पाइपलाइन जिसमें प्लग करने योग्य बहु-LLM संवर्धन (OpenAI/Anthropic/Ollama) शामिल है।
  • अंतर्निहित TTS (Bark, SpeechT5) और पृष्ठभूमि-संगीत निर्माण।
  • टूल-संवर्धित वृद्धि के लिए प्रोसेसिंग इंजन के भीतर MCP सर्वर कार्यान्वयन।
  • एक बैकएंड जो तीन प्रथम श्रेणी के क्लाइंट्स (Electron डेस्कटॉप, React Native मोबाइल, React वेब) को सेवा प्रदान करता है।

  • भारी मीडिया प्रोसेसिंग: Go पाइपलाइन और बैकग्राउंड जॉब प्रोसेसिंग के ज़रिए हल किया गया, ताकि लंबे TTS/वीडियो जॉब्स API को ब्लॉक न करें।
  • वैकल्पिक-पर-शक्तिशाली AI: LLM प्रदाताओं को वैकल्पिक और प्लग करने योग्य बनाकर हल किया गया, जिसमें बुनियादी कार्यक्षमता पर सहज वापसी की सुविधा है।
  • बहु-मंच वितरण: साझा REST API और तीन समर्पित प्लेयर ऐप्स के ज़रिए हल किया गया।
  • संचालन क्षमता: Docker Compose प्रोफाइल, Prometheus/Grafana और अंतर्निहित JWT प्रमाणीकरण के ज़रिए हल किया गया।

  • Go — कोर-प्रोसेसर इंजन, REST API, जॉब रनर, पाइपलाइन (972K+ बाइट्स, प्रमुख भाषा)।
  • TypeScript / React — वेब प्लेयर और साझा यूआई।
  • Electron — डेस्कटॉप क्रिएटर ऐप।
  • React Native — मोबाइल प्लेयर।
  • PostgreSQL — कोर्स/जॉब स्थायित्व।
  • LLM प्रदाता (OpenAI, Anthropic, Ollama) — सामग्री संवर्धन।
  • TTS (Bark, SpeechT5) — कथन संश्लेषण।
  • MCP सर्वर — इंजन के भीतर टूल एकीकरण।
  • Docker Compose + nginx — पूर्ण-स्टैक तैनाती और रिवर्स प्रॉक्सी।
  • Prometheus + Grafana — निगरानी।
